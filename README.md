# Учёт оплат учебного центра

Мини-сервис: ученики, оплаты и список должников за месяц.
**API на FastAPI + SQLite**, интерфейс — **веб-страница** (вариант Б), удобная на телефоне.

## Соответствие заданию

| Пункт задания | Где |
|---|---|
| 1.1 Ученики: имя, телефон, группа, месячная сумма; создание, список, изменение, удаление | `POST/GET/PUT/DELETE /students`, [`app/routers/students.py`](app/routers/students.py) |
| 1.2 Оплаты: ученик, сумма, дата; добавление и список по ученику | `POST /payments`, `GET /students/{id}/payments`, [`app/routers/payments.py`](app/routers/payments.py) |
| 1.3 Должники за месяц | `GET /debtors?month=YYYY-MM`, [`app/routers/debtors.py`](app/routers/debtors.py), SQL в [`app/queries.py`](app/queries.py) |
| 1.4 Любая БД | SQLite, схема в [`app/db.py`](app/db.py) |
| 2Б Веб-страница: должники + форма оплаты, удобно на телефоне | [`app/static/index.html`](app/static/index.html), открывается на `/` |
| 3 README: запуск и улучшения | ниже |

## Запуск с нуля

Нужен Python 3.10+ (проверено на 3.13). Больше ничего ставить не надо: база — файл SQLite, создаётся сама.

**Windows (PowerShell):**

```powershell
git clone <ссылка-на-репозиторий>
cd payments-tracker
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Если PowerShell отказывается запускать `Activate.ps1` (политика выполнения скриптов), выполните `Set-ExecutionPolicy -Scope Process Bypass` и повторите. Либо пропустите активацию и вызывайте `.venv\Scripts\python -m pip install -r requirements.txt` и `.venv\Scripts\python -m uvicorn app.main:app --reload`.

**Linux / macOS:**

```bash
git clone <ссылка-на-репозиторий>
cd payments-tracker
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

После запуска:

- веб-интерфейс — <http://127.0.0.1:8000/>
- документация API со встроенной проверкой запросов (Swagger) — <http://127.0.0.1:8000/docs>

Тесты:

```bash
pip install -r requirements-dev.txt
pytest
```

База лежит в `data/app.db`. Чтобы начать с чистой, остановите сервер и удалите этот файл. Другое расположение задаётся переменной окружения `DB_PATH`.

## API

| Метод | Путь | Что делает |
|---|---|---|
| `POST` | `/students` | создать ученика |
| `GET` | `/students` | список учеников |
| `GET` | `/students/{id}` | один ученик |
| `PUT` | `/students/{id}` | изменить (передаются все поля) |
| `DELETE` | `/students/{id}` | удалить вместе с его оплатами |
| `POST` | `/payments` | добавить оплату |
| `GET` | `/students/{id}/payments` | оплаты ученика, новые сверху |
| `GET` | `/debtors?month=YYYY-MM` | должники за месяц (без параметра — текущий) |

Примеры:

```bash
curl -X POST localhost:8000/students -H "Content-Type: application/json" \
  -d '{"name":"Алишер","phone":"+998 90 123 45 67","group":"English A1","monthly_fee":500000}'

curl -X POST localhost:8000/payments -H "Content-Type: application/json" \
  -d '{"student_id":1,"amount":200000,"date":"2026-10-05"}'

curl "localhost:8000/debtors?month=2026-10"
```

Ответ `/debtors`:

```json
{
  "month": "2026-10",
  "count": 1,
  "total_debt": 300000,
  "debtors": [
    {"student_id": 1, "name": "Алишер", "phone": "+998 90 123 45 67", "group": "English A1",
     "monthly_fee": 500000, "paid": 200000, "debt": 300000}
  ]
}
```

Ошибки: `404` — нет такого ученика, `422` — неверные данные (формат месяца, сумма ≤ 0, неверная дата и т. п.).

## Допущения

Задание оставляет несколько вопросов открытыми. Я решил так:

- **Долг за месяц** = месячная сумма ученика − сумма его оплат, дата которых попадает в этот месяц. Считается по дате оплаты, а не по «назначению платежа».
- Тот, кто не платил совсем, — должник на всю месячную сумму. Тот, кто заплатил ровно или больше, не показывается. Переплата на следующий месяц **не переносится**.
- Месячная сумма одна на все месяцы. Если её изменить, поменяется и долг за прошлые месяцы: истории тарифов нет.
- Даты поступления у ученика нет, поэтому за месяц до добавления в систему он тоже будет «должником».
- Суммы — целые числа в основных единицах валюты (без копеек). Валюта в интерфейсе задана константой `CURRENCY` в `index.html` (сейчас «сум»).
- Дата оплаты по умолчанию — сегодня. Даты в будущем разрешены (предоплата).
- Авторизации нет: сервис рассчитан на локальный запуск.

## Структура

```
app/
  main.py          приложение FastAPI, подключение роутов, отдача страницы

```

## Что улучшил бы, будь у меня ещё неделя

1. **Telegram-бот** (`/debt`, `/pay <id> <сумма>`) поверх тех же запросов: администратору удобнее вносить оплаты прямо из чата.
2. **Дата поступления и выбытия ученика**, а также история тарифов, чтобы долг считался только за месяцы обучения и не менялся задним числом.
3. **Авторизация и роли** (администратор / преподаватель), сейчас API открыт всем, кто достучится до сервера.
4. **Баланс вместо «долга за месяц»**: переплаты переносятся на следующий месяц, а долги накапливаются. Плюс отмена или правка ошибочной оплаты и экспорт в CSV.
5. **PostgreSQL, миграции (Alembic) и Docker** для деплоя, а также пагинация и поиск по ученикам, когда их станет много.

## Как использовался ИИ

Инструмент: **Claude Code** (модель Claude Sonnet 5.5), десктопное приложение. Веб-страницу проверял во встроенном в него браузере.

**Как шла работа.** Сначала я отдал ИИ текст задания и попросил полный разбор без кода. Получил список ловушек (условие по месяцу в `LEFT JOIN`, внешние ключи в SQLite, деньги целыми числами) и план. Потом мы выбрали стек и интерфейс и пошли по шагам: каркас, CRUD, оплаты, тесты, веб-страница, запрос должников. Тесты на должников написаны раньше самого запроса.

**Как проверялось.** Тесты (51) запускались после каждого шага. Правильность самих тестов проверена двумя способами: эталонным решением (все проходят) и намеренно сломанным запросом с условием по месяцу в `WHERE` (4 теста падают). План выполнения SQL смотрели через `EXPLAIN QUERY PLAN`: диапазон дат идёт по индексу. Страница проверена в браузере на ширине телефона (375 px), инструкция запуска прогнана с нуля на чистом клоне репозитория.

**Где ИИ ошибся и как это нашлось:**

- не настроил путь импорта для pytest: тесты не находили модуль `app`, это вылезло при первом запуске;
- предложил устаревшую зависимость `httpx`: Starlette выдал предупреждение и требует `httpx2`, я проверил это в его исходниках;
- в первой вёрстке телефон переносился на вторую строку, это видно только на скриншоте;
- написал в README «Python 3.11+», не проверив: по метаданным FastAPI достаточно 3.10.

**Кто что писал.** Весь код, включая SQL-запрос должников (`app/queries.py`), сгенерирован ИИ. Моя роль: я поставил задачу, выбрал стек и интерфейс, направлял работу и принимал результат.
